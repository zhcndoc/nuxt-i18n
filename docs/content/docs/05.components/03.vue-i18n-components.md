---
title: Vue I18n 组件
description: 继承自 Vue I18n 的翻译、日期时间和数字组件
---

除了此模块提供的组件外，底层的 [Vue I18n](https://vue-i18n.intlify.dev/) 库还提供了一组自有组件，这些组件可用于任何使用 `@nuxtjs/i18n` 的 Nuxt 应用。

| 组件                                                                          | 描述                                                                                   |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [`<i18n-t>`{lang="html"}](https://vue-i18n.intlify.dev/api/component.html#translation) | 用于将消息插槽插入渲染元素的翻译组件。        |
| [`<i18n-d>`{lang="html"}](https://vue-i18n.intlify.dev/api/component.html#datetime-format) | 用于渲染本地化日期和时间的日期时间格式化组件。            |
| [`<i18n-n>`{lang="html"}](https://vue-i18n.intlify.dev/api/component.html#number-format)   | 用于渲染本地化数字和货币的数字格式化组件。       |

有关完整的属性文档和示例，请参阅 [Vue I18n 组件 API 参考](https://vue-i18n.intlify.dev/api/component.html)。
